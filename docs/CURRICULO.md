**Sistema de Gestão de Quermesses — Projeto de Engenharia de Software**

Desenvolvi e evoluí uma aplicação web para organizar barracas, registros financeiros e conferência de comprovantes em quermesses. Refatorei um frontend existente de HTML/CSS/JavaScript para módulos ES, preservando seu design e funcionalidades. Implementei fluxos com Supabase Auth, PostgreSQL e políticas RLS, incluindo controle de acesso por perfil, compartilhamento autorizado de relatórios, correção de fechamentos e comparativos entre edições.

**Tecnologias:** JavaScript, HTML, CSS, Vite, SQL, PostgreSQL, Supabase Auth/Storage/Edge Functions, Git, GitHub Actions, Node.js (testes).

**Resultados demonstráveis:** arquitetura versionada, código público revisado, demonstração fictícia e documentação de segurança e implantação. Não declarar “em produção” ou “usado pela igreja” até confirmação real da implantação e do uso operacional.
